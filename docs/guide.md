# 사용 안내

이 사이트는 NR/6G **CSI 압축·예측·획득** 업무에 필요한 두 가지를 한곳에 모읍니다.

- **논문**: 매주 arXiv 새 논문 중 현재 3GPP 논의와 가까운 것을 골라 요약하고 점수를 매깁니다.
- **3GPP RAN1 논의**: 회의가 끝나면 관련 안건의 합의 사항, 남은 쟁점, 업체별 입장, 평가 결과를 정리합니다.

두 쪽은 서로 연결됩니다. 논문은 대응하는 RAN1 안건을 표시하고, 안건 요약에서는 관련 논문으로 넘어갈 수 있습니다.

## 메뉴 한눈에

| 메뉴 | 무엇을 보나 | 이럴 때 |
|---|---|---|
| **홈** | 현황, 최근 추가 논문, 최신 RAN1 요약 | 이번 주에 무엇이 새로 들어왔나 |
| **논문 › 논문 목록** | 전체 논문을 3GPP 안건별로 묶은 목록 (점수순, 한 줄 결론) | 특정 안건(예: 9.1.1)에 참고할 논문을 찾을 때 |
| **논문 › 비교 표** | 지표 · 채널 모델 · 압축률 · 성능을 한 표에서. 필터·정렬·**링크 복사** | 조건을 걸어 논문을 비교하거나 팀원에게 같은 화면을 보낼 때 |
| **3GPP Tdoc 요약** | 안건 × 회의 지도와 안건별 요약 | 어떤 안건이 어디까지 합의됐는지 볼 때 |
| **3GPP Tdoc 요약 › 업체별 입장** | 업체마다 안건별 Tdoc 원문 · 입장 · 핵심 제안 | 특정 업체가 무엇을 주장했는지 볼 때 |
| **안내 › 점수 기준** | 3GPP 관련성 등급과 100점 rubric | 점수가 어떻게 매겨졌는지 확인할 때 |

## 처음이라면 이렇게 보세요

1. **홈**에서 최근 추가 논문과 최신 RAN1 요약을 훑어봅니다.
2. 관심 있는 안건을 골라 **3GPP Tdoc 요약**에서 합의 흐름과 남은 쟁점을 읽습니다.
3. 같은 안건의 논문을 **논문 목록**에서 점수순으로 보고, 필요하면 **비교 표**에서 조건을 걸어 비교합니다.

## 논문 페이지 읽는 법

- 맨 위 **결론 박스**에 점수, 대응 3GPP 안건, 핵심 결과(baseline 대비), 우리 업무 관점의 한 줄 결론이 있습니다. 대부분은 여기까지만 읽어도 충분합니다.
- 그 아래 정보 카드(저자·소속·게재·채널 모델 등)와 본문 절(Key idea → System model → Simulation setup → Results → Limitations → 우리 업무 관점 코멘트)이 이어집니다.
- 맨 아래 **점수 근거** 표에 항목별 점수와 근거(논문의 절·표·그림 번호)가 있습니다.
- 수치 앞의 `≈` 는 논문 **그래프에서 읽은 값**입니다. 표·본문 값은 출처와 함께 그대로 적습니다.
- **abs** 또는 ⚠️ *abstract only* 표시는 전문을 읽지 못해 초록만으로 요약한 논문입니다. 수치와 점수는 잠정치입니다.

## 점수 한눈에

| 색 | 점수 | 뜻 |
|---|---|---|
| <span class="csi-score csi-score--high">70+</span> | 70 이상 | 근거가 탄탄해 바로 참고할 만함 |
| <span class="csi-score csi-score--mid">50–69</span> | 50–69 | 아이디어는 유용하나 가정·비교 조건 확인 필요 |
| <span class="csi-score csi-score--low">&lt;50</span> | 50 미만 | 참고용 |

점수는 **3GPP 관련성(15점)** 과 게재처, 채널 모델, 가정의 현실성, baseline 공정성, 재현성, 복잡도 분석, 산업체 저자, TR 38.843 평가 가정 준수를 합친 100점입니다.
3GPP 관련성은 15(현재 안건과 직접 일치 + 3GPP 방식 평가) / 11(둘 중 하나) / 7(NR/6G CSI 일반) 세 단계입니다.
자세한 기준은 [점수 기준](rubric.md)을 보세요. 점수는 아이디어의 참신함이 아니라 "우리 업무에 그대로 가져다 쓸 수 있는 근거가 얼마나 탄탄한가"입니다.

## Tdoc 요약 읽는 법

- 안건 요약은 **지금까지의 합의 흐름 → 이번 회의 합의 사항 → 남은 쟁점 → 업체별 주요 제안 → 평가 결과 → 우리 업무 관점 코멘트** 순서입니다.
- "업체별 주요 제안"의 주제별 표에서 **업체 이름을 누르면 그 업체 Tdoc 원문(zip)** 을 받습니다. 맨 아래 "업체별 입장 모아 보기"를 펼치면 업체마다 입장을 모아 볼 수 있습니다.
- 입장 분류는 FL summary · Summary of proposals 기준이며, 출처 문서를 표 머리말에 적습니다.
- **최종**은 회의 종료 의장 노트 기준, **잠정**은 회의 중 FL summary 기준입니다.

## 용어 풀이

SGCS, NMSE, eType II, CBSR 처럼 점선 밑줄이 있는 용어는 마우스를 올리면 짧은 설명이 나옵니다.

| 용어 | 뜻 |
|---|---|
| CSI 압축 / 피드백 | UE가 측정한 하향링크 채널 정보를 적은 비트로 줄여 기지국에 보고하는 것 |
| CSI 예측 | 과거 채널로 미래 채널을 추정해 channel aging(보고와 사용 사이의 채널 변화)을 줄이는 것 |
| two-sided 모델 | UE의 encoder와 기지국의 decoder가 짝을 이루는 AI 모델. 서로 다른 업체가 만들면 학습 협업이 필요(9.1.2) |
| Case 0 | Rel-20 AI/ML CSI에서 시간축 없이 공간·주파수만 압축하는 사례(9.1.1) |
| SGCS | 복원한 CSI(고유벡터)와 실제의 방향 유사도. 1에 가까울수록 좋음 (TR 38.843 주 지표) |
| NMSE | 복원·예측 오차를 실제 채널 크기로 나눈 값. dB로 낮을수록 좋음 |
| eType II | Rel-16 고해상도 CSI 코드북. AI 압축의 기본 비교 대상(baseline) |
| PMI · CSI-RS · SRS | 코드북 precoder 번호 · 하향링크 측정 기준 신호 · UE가 보내는 상향링크 측정 신호 |
| 6GR | 3GPP Rel-20 6G 무선 접속 연구 (10.5 안건) |
| FL summary | 안건 진행자(Feature Lead)가 업체 제안을 정리한 문서 |
| LLS · SLS | 링크 레벨 · 시스템 레벨 시뮬레이션 |
