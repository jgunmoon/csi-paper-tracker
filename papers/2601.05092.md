## Key idea

- 5G NR PMI(코드북 기반 빔포밍)를 이론·표준·구현 관점에서 정리한 튜토리얼 (Abstract).
- Rel-15–18 코드북 진화: regular / port-selection, Type I / Type II, eType II, Doppler(Rel-18) 코드북의 설계 원리와 수식 기호의 물리 의미를 표로 정리 (Sec. III–V).
- 코드북별 단순화 모델로 성능 차이와 피드백 overhead, 적용 시나리오를 비교하고 향후 연구 방향 제시 (Sec. VI).

## System model

- CSI-RS 측정–PMI 피드백 절차, 논리/물리 안테나 배열 매핑 (Fig. 1–4).

## Results (baseline 대비)

- 제안 기법이 없는 튜토리얼이라 baseline 대비 이득은 없다. Type I → Type II → eType II → Doppler 코드북으로 갈수록 표현력과 overhead가 함께 늘어나는 관계를 정리 (Sec. VI).
- 코드북 파라미터를 TS 38.214 표와 대응시켜 정리 (Table I–IV 등).

## Limitations

- 3GPP 시스템 레벨 평가 수치를 새로 제시하지 않는다. Rel-19 이후 내용은 전망 수준.

## 우리 업무 관점 코멘트

- **RAN1#127 안건 대응: 10.5.3.1 (6GR 하향링크 기반 CSI 획득, 배경 자료).** 6GR 코드북 논의의 출발점인 NR 코드북 구조를 기호 수준까지 정리한 자료라, 신규 인원 교육과 6GR 코드북 제안 검토의 참고서로 쓸 수 있다.
- 논문 점수가 낮은 것은 평가 논문이 아니기 때문이며, 참고 자료로서의 가치는 높다.
