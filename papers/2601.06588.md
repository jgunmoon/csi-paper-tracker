## Key idea

- 손실 압축은 CNN(지역)과 Swin Transformer(전역)를 섞은 가벼운 encoder로, 그 뒤 latent는 **언어 모델(LM)·factorized model 기반 무손실 부호화**로 비트화한다 (Fig. 2–4).
- 고정 길이 부호화 대신 rate–distortion–complexity 균형을 맞추는 가변 비트 피드백.
- LLM을 zero-shot 무손실 압축기로 쓰는 가능성도 시험.

## System model

- FDD massive MIMO, angular-delay 영역 CSI (식 (1)).

## Simulation setup

| 항목 | 값 |
|---|---|
| 채널 모델 / 시나리오 | COST2100, 실측 MIMO 데이터 |
| 지표 | NMSE, FLOPs, 비트 수 |
| Payload | CR 1/4–1/128 |
| 코드·데이터 공개 | 없음 |

## Results (baseline 대비)

- CR 1/8: CNN 기반 대비 **NMSE 최대 4 dB**, TransNet 대비 1–2 dB 개선, FLOPs는 TransNet의 ≈ 1/3 (Sec. IV).
- CR 1/64·1/128에서도 TransNet 대비 ≈ 0.5 dB (Sec. IV).
- 실측·시뮬레이션 전체에서 최대 5 dB 이득 (Abstract).

## Limitations

- 가변 길이 비트열은 고정 크기 UCI와 맞지 않고, LM 부호화는 UE 쪽 연산을 늘린다.
- eType II·SGCS 비교가 없다.

## 우리 업무 관점 코멘트

- **RAN1#127 안건 대응: 9.1.1 (Case 0 CSI 압축).** 양자화 뒤 무손실 부호화로 비트를 줄이는 단계는 Case 0 payload 설계에서 거의 다뤄지지 않은 부분이라 아이디어 참고용으로 볼 만하다.
- 다만 가변 길이 보고는 현재 CSI 보고 틀(고정 payload)과 맞지 않아 표준 관점에서는 제약이 크다.
- 실측 데이터 결과가 있다는 점은 sim-to-real 논의에 보조 근거가 된다.
