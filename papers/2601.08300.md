## Key idea

- U6G(6425–7125 MHz) 광대역에서 angular-delay 절단 시 DFT 기저 에너지 누설이 커지는 문제를 피하려고, 주파수 영역은 **Loewner 보간(LI)** 으로 적은 수의 표본에서 CSI를 복원한다 (Fig. 1–2).
- 공간 영역은 tail dropout으로 학습한 rateless AE로 압축해 **모델 하나로 가변 길이 피드백**을 지원 (Fig. 3).
- codeword를 중요도 순으로 정렬하고 적응 양자화를 붙여 뒷부분 손실에도 견딘다.

## System model

- FDD massive MIMO, U6G 광대역 (Table I).

| 항목 | 값 |

| 대역 | U6G 6425–7125 MHz |
| 지표 | NMSE(양자화 전·후), SE, FLOPs |
| Payload | 가변 길이, 양자화 |
| 코드·데이터 공개 | 없음 |

## Results (baseline 대비)

- 같거나 적은 overhead에서 baseline보다 높은 복원 정확도와 SE (Abstract, Fig. 6·8·9 — 그림 수치 미확인).
- 공간 압축·복원 AE 91.8 MFLOPs, LI 복원은 O(2·N_T·N_sc·r_f) (Sec. IV, Table II).

## Limitations

- 그림을 렌더링하지 않아 baseline 대비 정량 이득을 옮기지 못했다.
- 가변 길이 보고는 고정 UCI와 맞지 않고, eType II 비교가 없다.

## 우리 업무 관점 코멘트

- **RAN1#127 안건 대응: 10.5.3.1 (6GR 하향링크 기반 CSI 획득).** U6G 광대역에서 주파수 영역 압축을 보간 모델로 바꾸는 접근은 6GR 광대역 CSI 보고(주파수 기저 설계) 논의에 참고할 만하다.
- CDL을 써서 우리 6GR 평가 조건으로 옮기기 쉬운 편이다. 원문 그림에서 baseline 대비 수치를 확인해 보충할 필요가 있다.
