## Key idea

- precoding-oriented CSI 피드백(잡음 pilot → 비트 → BS precoder)을 VQ-VAE로 만들고, **상호정보량(MI) 하한 추정기**를 정규화 항으로 넣어 codeword가 고르게 쓰이도록 학습한다 (Sec. III).
- 기존 방식은 일부 codeword만 쓰여(codebook collapse) 주어진 비트를 다 활용하지 못한다는 문제의식.
- 학습된 codeword가 채널 파라미터와 상관된 구조를 보여 해석 가능성도 있다고 주장 (Fig. 3).

## System model

- FDD 하향링크, BS 64 안테나 · 단일 안테나 UE 2명, 경로 2개, UE당 pilot 8개 (Table I).
- UE가 잡음 pilot 관측을 B bits로 매핑 → BS가 모든 UE 비트로 precoder 설계.

## Simulation setup

| 항목 | 값 |
|---|---|
| 채널 모델 / 시나리오 | 경로 2개 기하 모델 |
| 안테나 | BS 64, UE 1 (2명) |
| 지표 | 합 전송률, codeword 사용 분포 |
| Payload | UE당 5–60 bits |
| 코드·데이터 공개 | 없음 |

## Results (baseline 대비)

- 10 bits/UE: **≈ 13.5 vs DL 기반 [7] ≈ 12.5 bits/ch. use**; 20 bits에서 ≈ 14.5 vs ≈ 13.9 (Fig. 2).
- 25 bits 이상에서는 entropy coding 방식 [8]이 ≈ 15.0으로 제안(≈ 14.8)보다 약간 높다 (Fig. 2). 완전 CSIT ZF 상한은 ≈ 15.3.
- 10 bits에서 codeword 사용 분포가 [7]보다 훨씬 고르다 (Fig. 4).

## Limitations

- 경로 2개·UE 2명의 단순 설정이라 실제 다중 경로 광대역 채널로의 확장은 미검증.
- 고비트 영역에서는 기존 entropy coding보다 못하고, 복잡도 분석이 없다.

## 우리 업무 관점 코멘트

- **RAN1#127 안건 대응: 직접 해당 없음.** pilot·피드백·precoder를 한꺼번에 학습하는 end-to-end 구조라 eigenvector를 압축·보고하는 Case 0(9.1.1)이나 6GR CSI 보고 틀과는 거리가 있다.
- "VQ codebook 사용률을 MI로 고르게 한다"는 학습 기법은 우리 VQ 기반 Case 0 모델의 codebook collapse 문제에 바로 써 볼 수 있다.
- 채널 모델이 단순해 수치를 근거로 인용하기는 어렵다.
