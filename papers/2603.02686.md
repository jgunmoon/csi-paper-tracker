## Key idea

- CSI 압축 피드백을 **masked token 예측**으로 다시 정의해 LLM 백본으로 복원하는 LLMCsiNet (Sec. III).
- 자기정보량(self-information) 기반으로 중요한 token만 남기는 마스크 선택, UE는 가벼운 encoder만 둔다.
- 추가 복잡도는 자원이 많은 BS 쪽에 몰아 둔다.

## System model

- FDD massive MIMO, angular-delay 영역 잘라낸 CSI (N_c × N_t) (Sec. II).

## Simulation setup

| 항목 | 값 |

| 채널 모델 / 시나리오 | COST2100 indoor/outdoor, UMa, DeepMIMO O1 |

## Results (baseline 대비)

- COST2100 outdoor CR 1/8: baseline CRNet −7.05, IdasNet −9.78, TransInDecNet −6.51, GCRNet −6.73 dB 대비 **LLM 크기에 따라 ≈ 3.5–9 dB 개선** (Sec. V-B).
- 다른 데이터셋 CR 1/8 baseline 범위 −12.14(CRNet)–−15.34 dB(IdasNet) 대비도 우위 (Sec. V-B, 그림 수치 미확인).
- UE encoder 추론 시간은 작고, 증가분은 BS decoder에 몰림 (Fig. 6).

## Limitations

- BS에 LLM을 두는 비용(메모리·지연)이 커서 실시간 CSI 처리에 맞는지 따로 봐야 한다.
- eType II 비교와 UE 측 채널 추정 오차가 없다.

## 우리 업무 관점 코멘트

- **RAN1#127 안건 대응: 9.1.1 (Case 0 CSI 압축).** UE는 가볍게, NW는 대형 모델로 두는 비대칭 two-sided 구조의 성능 상한을 보여 주는 사례로 Case 0 논의에 참고할 수 있다.
- UMa 데이터셋에서의 SGCS 결과(Table III)는 우리 평가와 비교 가능한 축이라 원문 표 확인 후 인용 가능.
- LLM decoder의 지연·메모리는 6GR 처리 시간 요구와 함께 따져야 한다.
