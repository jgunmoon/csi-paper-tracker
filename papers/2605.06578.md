## Key idea

- GRU encoder + Luong attention을 **gated fusion**으로 합치고, 다단계 출력을 축별로 분해한 선형 head(DSLH)로 만들어 큰 dense 출력층을 없앤다 (Sec. III, Fig. 1).
- 목표는 transformer 계열과 비슷한 정확도를 더 적은 파라미터·더 빠른 추론으로 얻는 것.
- UE 속도를 입력에 붙이면 정확도가 더 오른다 (Table VII).

## System model

- 하향링크 협대역 MIMO H_t ∈ C^{R×T}, **대표 subcarrier 하나**만 다룬다 (Sec. II).
- 이력 N_P 샘플로 미래 다단계 예측.

## Results (baseline 대비)

- 평균 NMSE **−13.84 dB**, LinFormer(차원 맞춤) 대비 파라미터 −26%, 처리량 ≈ 2.3배 (Abstract, Table III).
- 시나리오별: Scenario V(UMa LOS) −18.27 vs LinFormer −17.73 dB, 학습 범위 밖 고속 Scenario IV −10.81 vs −10.95 dB (Table IV). 5개 중 3개에서 LinFormer보다 낫다.
- gated fusion이 선형 fusion보다 +0.66 dB(−13.18 → −13.84 dB), UE 속도 입력 시 +0.65–1.72 dB (Table VI, VII).

## Limitations

- 단일 subcarrier 협대역이라 광대역 OFDM 예측과는 차원이 다르다(저자도 future work로 명시).
- 이력 CSI가 noise-free이고, Kalman·AR 같은 모델 기반 예측기 비교가 없다. SGCS 미보고.

## 우리 업무 관점 코멘트

- **RAN1#127 안건 대응: 직접 해당 없음.** UE 측 CSI 예측은 Rel-19에서 마무리되었고 Rel-20 9.1.x는 Case 0 압축·inter-vendor 협업이라 직접 닿는 안건이 없다. 6GR CSI에서 예측을 다시 다룰 때 경량 예측기 사례로 참고할 수 있다.
- 사업자(Turkcell) 공저에 38.901 QuaDRiGa·학습 밖 속도 시험을 갖춰 경량 GRU의 정확도–복잡도 trade-off 근거로는 쓸 만하다.
- 광대역·잡음 이력으로 확장해 SGCS로 다시 재야 우리 Rel-19 예측 평가와 비교할 수 있다.
