## Key idea

- mmWave 차량 사용자의 빔 전환을 CSI 피드백에 반응해서 하지 않고, **CSI를 예측해 미리 준비**한다 (Sec. I).
- 학습 데이터는 CSI 피드백과 주변 차량의 C-V2X CAM(위치·속도) 메시지를 결합해 만들고, 라벨링·학습·추론을 O-RAN rApp/xApp으로 자동화한다 (Sec. III–IV).
- 단독(gNB별)과 연합학습(FL) 두 모드를 지원한다.

## System model

- 5G mmWave gNB 4곳, 실제 이동 데이터 기반 DeepMIMO 도심 차량 시나리오 (Fig. 2, Table I).
- LSTM 기반 CSI 예측 모듈(CSI-PM), 1D-CNN·Transformer를 비교 구조로 둔다 (Fig. 3).

## Simulation setup

| 항목 | 값 |
|---|---|
| 채널 모델 / 시나리오 | DeepMIMO 도심 차량, gNB 4곳 (BS1–BS4) |
| 학습 / 시험 데이터 | 데이터셋별 70% 학습 / 30% 시험, FL 20 라운드 |
| 예측 간격 | Δτ = 100–1000 ms |
| 지표 | NMSE(선형), FLOPs, 추론 시간 |
| 코드·데이터 공개 | 없음 |

## Results (baseline 대비)

- NMSE(선형): LSTM 0.0094 / 0.011 / 0.0095 / 0.018 vs 1D-CNN 0.011 / 0.019 / 0.012 / 0.023, Transformer 0.0096 / 0.0108 / 0.0094 / 0.018 (BS1–BS4, Table V). LSTM과 Transformer가 비슷하고 1D-CNN이 가장 나쁘다.
- CSI 품질 ≈ 10 dB 이상이면 학습–추론 조건이 달라도 ideal-CSI 기준에 근접 (Fig. 6).
- Δτ = 1000 ms에서도 100 ms 대비 NMSE 증가가 작고, UE 안테나 1 → 8개로 늘려도 저하가 작다. FL 모드 최종 NMSE 0.0159 (Table VI, VII).

## Limitations

- 빔 전환 자체의 성능(빔 예측 정확도, throughput)이 아니라 CSI 예측 NMSE만 평가했다.
- Kalman 등 모델 기반 예측기와의 비교가 없고, DeepMIMO 단일 도시라 일반화는 미검증.

## 우리 업무 관점 코멘트

- **RAN1#127 안건 대응: 10.5.3.4 (6GR 빔 관리, 현재 보류 항목).** CSI 예측을 빔 전환 준비에 쓰는 구조는 6GR 빔 관리의 예측 기반 절차 논의에 사례로 쓸 수 있다. 다만 우리 Tdoc 추적 범위에서 10.5.3.4는 보류 중이다.
- C-V2X 위치 정보를 보조 입력으로 쓰는 점은 Rel-19 빔 예측(BM-Case2)의 보조 정보 논의와 닿는다.
- 평가가 NMSE에 그쳐, 빔 예측 정확도(Top-K)로 다시 평가해야 3GPP 빔 관리 평가와 비교할 수 있다.
