## Key idea

- OMP의 반복 원자 선택을 **가벼운 CNN 지연(탭) 예측기**로 대신하고, 공간 진폭은 닫힌 형태의 LS로 구하는 TAP(Tap-Assisted Parametric) 압축 (Sec. III, Fig. 3).
- payload가 탭 위치·계수라 BS는 신경망 없이 **IFFT만으로 복원**(decoder-free).
- 안테나 수와 무관한 구조라 배열 크기·환경이 바뀌어도 다시 학습하지 않는다(zero-shot).

## System model

- FDD massive MIMO, CFR을 지연 영역에서 희소하게 표현 (Sec. II). 평가 기본은 1×32 ULA.

## Simulation setup

| 항목 | 값 |
|---|---|
| 채널 모델 / 시나리오 | CDL UMa·UMi·InF·InH, Sionna RT, DeepMIMO |
| 안테나 | 1×32 ULA (확장성 별도) |
| 지표 | CFR-NMSE(평균·P90·P95), 모델 크기, 지연 |
| 코드·데이터 공개 | 없음 |

## Results (baseline 대비)

- 평균 CFR-NMSE: **UMa −25.88 dB, InF −37.01 dB, UMi −32.82 dB, InH −31.78 dB** vs 같은 조건 CsiNet −15.54 dB (Table II).
- CsiNet 계열 대비 UMa에서 10.0–11.1 dB, InF에서 3.13–12.22 dB 이득, 모델은 1/660(1 MB 미만) (Conclusion).
- iterative OMP 대비 추론 2700배 빠르고 5G NR 서브 ms 예산 안 (Abstract).

## Limitations

- far-field 지연 희소성 가정이라 near-field 대형 배열에는 그대로 적용하기 어렵다(저자 명시).
- eType II·SGCS 비교가 없고, 비교 대상이 오래된 CsiNet 계열이다.

## 우리 업무 관점 코멘트

- **RAN1#127 안건 대응: 9.1.1 (Case 0 CSI 압축).** BS 쪽 AI decoder가 필요 없는 parametric 압축이라, Case 0에서 "two-sided 대신 UE 측 one-sided에 가까운 구조" 대안으로 비교해 볼 만하다.
- 배열 크기와 무관한 구조는 Case 0 일반화(안테나 수 변경) 논의의 좋은 대조군이다.
- 우리 평가로 옮기려면 eigenvector 입력·SGCS·eType II 대비로 다시 재야 한다.
