## Key idea

- 하나의 큰 일반 모델 대신, **장면별 작은 CSI 압축 모델 저장소(Learnware)** 를 AI 데이터센터에 두고 상황에 맞는 모델을 골라 쓴다 (Fig. 1).
- 각 모델에는 구조 정보(semantic)와 학습 데이터 분포를 요약한 **codebook 지문(codeword 사용 빈도)** (statistical)을 사양으로 붙인다. 원 CSI 데이터를 보내지 않고 지문 유사도로 모델을 찾는다 (Sec. III–IV).
- 필요하면 임계값 기준으로 소량 fine-tuning.

## System model

- FDD, UE encoder–BS decoder CSI 압축. 저장소는 데이터센터, BS는 지문을 계산해 모델을 받아 배포 (Fig. 6).

## Simulation setup

| 항목 | 값 |
|---|---|
| 채널 모델 / 시나리오 | QuaDRiGa, LOS/NLOS 하위 영역(5 m × 5 m)별 데이터셋 |
| 학습 / 시험 데이터 | 85/10/5% 분할, 장면 교차 시험 |
| 지표 | SGCS, 모델 선택 정확도, 검색 지연 |
| 코드·데이터 공개 | 없음 |

## Results (baseline 대비)

- 저장소 선택 vs General Model: **SGCS +18.8% (LOS, 0.147/0.781), +57.7% (NLOS, 0.169/0.293)**, fine-tuning 샘플 최대 1000개·100 epoch 절감 (Sec. VI).
- 장면별 CNN(2k 파라미터, 0.11M FLOPs)이 파라미터 1000배·연산 5600배인 transformer General Model보다 모든 장면에서 높다 (Sec. VI).
- 지문 기반 검색: 선택 정확도 90% 이상, 얕은 단계 0.25–0.60 ms(85.9–91.9%), 깊은 단계 0.90–1.15 ms(97.0–99.0%) (Sec. VI).

## Limitations

- 장면을 5 m × 5 m 하위 영역으로 잘게 나눈 설정이라, 실제 셀 단위 배포에서 모델 수·저장 비용이 얼마나 될지는 불명확하다.
- 피드백 비트·양자화 조건이 분명하지 않고 eType II 비교가 없다.

## 우리 업무 관점 코멘트

- **RAN1#127 안건 대응: 9.1.1 (Case 0, 일반화·장면별 모델).** "작은 장면별 모델 + 데이터 분포 지문으로 선택"은 Case 0 평가에서 일반화 Case(시나리오 변경)를 다루는 다른 방법으로 참고할 만하다.
- codebook 지문으로 데이터 분포를 요약해 원 데이터 없이 모델을 고르는 아이디어는 9.1.2에서 데이터셋 공유 부담을 줄이는 방향과도 닿는다.
- 우리 38.901 UMa 평가에서는 장면 정의가 다르므로, 셀·UE 분포 단위로 지문을 다시 정의해야 재현할 수 있다.
