## Key idea

- Rel-20이 two-sided CSI 피드백 모델 pairing까지 LCM을 넓혔지만, 모니터링이 성능 저하를 감지했을 때 **교정 조치가 얼마나 빨리 적용돼야 하는가**는 정해지지 않았다는 문제 제기 (Sec. 1–2).
- 활성화·rollback 전략 3종을 대리 환경에서 명령 지연을 바꿔 가며 시험하고, L2 trigger(빠른 제어 경로) 필요성을 주장 (Sec. 3, Table 1).

## System model

- regime shift가 있는 대리 환경, 독립 학습한 PPO 정책 150개 × 잡음 20회 (Sec. 3).

## Simulation setup

| 항목 | 값 |
|---|---|
| 환경 | 대리(surrogate) regime-shift 환경, 시간 단위는 control step |
| 전략 | hard cutover, KPI 임계 rollback, stability-gated blending |
| 지표 | shift 이후 누적 SLA 결손 |
| 코드·데이터 공개 | 없음 |

## Results (baseline 대비)

- 지연 0: blending이 누적 SLA 결손 **47.02 → 7.57**(hard cutover 대비 −83.9%) (Abstract).
- 지연 40 step: 44.38로 이점이 5.6%로 줄고, KPI rollback은 몇 구간 만에 이점을 거의 잃는다 (Fig. 1).

## Limitations

- CSI·무선 채널이 없는 대리 환경이고 step을 실제 시간으로 바꾸지 않아, RAN 타임라인 수치로 옮길 수 없다(저자 명시).
- 개인 연구자 단독 연구로 검증 범위가 좁다.

## 우리 업무 관점 코멘트

- **RAN1#127 안건 대응: 9.1.2 (two-sided 모델 inter-vendor 운용, 간접).** 모델 pairing·전환의 **제어 지연 요구**를 정해야 한다는 문제 제기라, LCM 시그널링(L1/L2 vs 상위 계층) 논의에서 문제 정의 참고용으로만 쓸 수 있다.
- 수치는 대리 환경 값이라 근거로 인용하지 않는다.
