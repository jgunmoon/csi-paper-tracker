## Key idea

- UE와 BS가 모두 아는 **평균 angle–delay 전력 지도(2차 통계)** 를 사전 정보(prior)로 써서, 압축할 latent token 중 정보가 많은 것만 고르는 masked VQ(PM-VQ)를 제안한다 (Sec. III–IV).
- spatially-adaptive masking module(SAMM)이 token을 고르고, BS의 prior-free 복원 모듈(ADM)이 빠진 위치를 채운다.
- 선택 token 수를 학습 때 무작위로 바꿔, **모델 하나로 여러 feedback 크기**를 지원한다 (variable-rate).

## System model

- FDD massive MIMO, UE가 angle–delay 영역 CSI를 VQ로 비트화 후 잡음 있는 UL로 전송(SSCC). JSCC와 비교 (Sec. II).
- OFDM 50 RB × 12 subcarrier(600 subcarrier, 18 MHz), 30 kHz.

## Simulation setup

| 항목 | 값 |
|---|---|
| 채널 모델 / 시나리오 | Sionna 3GPP TR 38.901 UMa, 채널 에너지가 퍼진 diffuse 영역 위주 |
| 대역폭 | 18 MHz (600 subcarrier) |
| 학습 / 시험 데이터 | 같은 분포 |
| 지표 | NMSE |
| Payload | β_fb (UL 복소 채널 사용 수) 가변, UL SNR −5–20 dB |
| 코드·데이터 공개 | 없음 |

## Results (baseline 대비)

- β_fb = 128, UL SNR 20 dB: **PM-VQ NMSE ≈ −8.2 dB** vs SSCC baseline ≈ −3.4 dB, JSCC baseline ≈ −2.7 dB, OMP ≈ −0.3 dB (Fig. 2a). UL SNR이 높을수록 격차가 커진다.
- prior를 빼면(PM-VQ No Prior) 20 dB에서 ≈ −5.7 dB로, prior가 ≈ 2.5 dB를 기여한다 (Fig. 2a).
- 고정 UL SNR 20 dB에서 β_fb를 늘리면 모든 방식의 NMSE가 낮아지고 PM-VQ가 가장 낮다 (Fig. 3a, 그림 수치 미확인).

## Limitations

- NMSE만 보고하고 SGCS·eType II 비교가 없다. 가장 어려운 diffuse 영역을 골라 평가했으므로 일반 UMa 분포에서의 이득은 따로 봐야 한다.
- 복잡도 분석이 없고, prior(평균 전력 지도)를 UE·BS가 공유하는 절차와 갱신 비용은 다루지 않는다.

## 우리 업무 관점 코멘트

- **RAN1#127 안건 대응: 9.1.1 (Case 0 CSI 압축).** 2차 통계를 양쪽이 공유하는 prior로 쓰고 모델 하나로 여러 payload를 지원하는 구조라, Case 0의 payload별 모델 수 문제와 직접 닿는다.
- 공유 prior는 사실상 **양쪽이 맞춰야 하는 추가 정보**라, 9.1.2 inter-vendor 협업에서 무엇을 공유할지 논의할 때 사례로 쓸 수 있다.
- 우리 평가 체계로 옮기려면 eigenvector 입력·SGCS·eType II 대비로 다시 재야 한다. UL 잡음 채널까지 넣은 평가는 3GPP 가정(이상적 UCI)과 다르다.
