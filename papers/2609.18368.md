## Key idea

- 채널을 복원하는 대신, UE가 **빔 선택에 필요한 의미(semantic) 임베딩** d = 8개 실수만 보내고 gNB가 바로 최적 빔을 예측한다 (Fig. 1).
- 입력 영역(공간–주파수 vs angular–delay)과 관측 밀도(전체 CSI vs 희소 pilot)를 바꿔 비교.
- 설계 요령: pilot을 angular–delay로 변환, 빈 subcarrier는 보간하지 않음, 8차원으로 압축해 빔 예측으로 end-to-end 학습.

## System model

- FDD, gNB 2D DFT 빔 코드북(256 후보), UE는 NR CSI-RS pilot 43개(512 subcarrier의 8.4%)만 관측 (Sec. 2).

## Simulation setup

| 항목 | 값 |
|---|---|
| 채널 모델 / 시나리오 | DeepMIMO v4 asu_campus_3p5, 3.5 GHz |
| 관측 | 전체 CSI / pilot 43개 / 잡음 |
| 지표 | Top-1 빔 정확도 |
| Payload | d = 8 실수 (4 bits/값 → 32 bits 가정) |
| 코드·데이터 공개 | 없음 |

## Results (baseline 대비)

- pilot 43개 + angular–delay + semantic: **Top-1 89.1%**, 전체 CSI 공간–주파수 + semantic 83.5%보다 높다 (Sec. 4, Table 1).
- 같은 d = 8 병목의 복원형 CsiNet은 2–6%로 무작위(≈ 1.1%)에 가깝다 (Fig. 3).
- 최적 입력 영역은 관측 밀도에 따라 뒤바뀐다: 전체 CSI면 공간–주파수, 희소 pilot이면 angular–delay (Fig. 2).

## Limitations

- 양자화 인지 학습과 장면 간 일반화는 future work로 남았다.
- 단일 캠퍼스 장면·단일 사용자 관측이라 다중 셀·이동 조건에서는 미검증.

## 우리 업무 관점 코멘트

- **RAN1#127 안건 대응: 10.5.3.4 (6GR 빔 관리, 현재 보류 항목).** CQI/PMI 수준 payload(≈ 32 bits)로 빔을 직접 예측하는 Ericsson 제안이라, 6GR에서 빔 보고와 CSI 보고를 통합하는 방향의 업체 근거로 볼 수 있다.
- "복원형 압축은 빔 선택에 필요한 정보를 잃는다"는 결과는 task-oriented CSI 보고(9.1.x 이후) 논의의 동기 자료가 된다.
- DeepMIMO 단일 장면이라 수치는 참고용으로만 쓴다.
