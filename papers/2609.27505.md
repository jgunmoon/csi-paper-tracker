## Key idea

- 기존 코드북 피드백은 UE별 **물리 채널**을 압축하므로, BS precoder와 간섭을 고려한 UE combiner 사이에 어긋남이 생긴다 (Sec. I).
- ECSI: UE가 precoded 하향 pilot으로 자기 combiner를 계산하고, **결합 후 유효 채널**을 기존과 같은 payload 구조로 양자화해 보고한다 (Sec. III).
- 다중 셀 협력 시 간섭 BS의 유효 채널도 보고해 간섭 인지 precoding, 표준 하향 pilot으로 OTA 반복 개선.

## System model

- 다중 셀 협력 다중 사용자 MIMO 하향링크, 다중 안테나 UE, 협대역(단일 subband) (Sec. II).

## Simulation setup

| 항목 | 값 |
|---|---|
| 채널 모델 / 시나리오 | 협대역 cluster 모델, 다중 셀 |

| 지표 | 합 전송률, 스트림별 rate 분포, 유효 채널 오차 |
| 코드·데이터 공개 | 없음 |

## Results (baseline 대비)

- 기존 CSI 기반 precoding 대비 **평균 합 전송률 최대 +30%** (Abstract).
- 간섭 제한 조건에서 하위 10% 스트림 rate 최대 **+100%** (ECSI-SC·ECSI-IC 각각 기존 대비) (Sec. V).
- 몇 번의 반복으로 수렴, 이득은 셀 경계·간섭 제한 UE에서 크다 (Fig. 1–2).

## Limitations

- 협대역 단일 subband 가정이라 광대역 주파수 압축과의 결합은 다루지 않는다.
- OTA 반복에 필요한 precoded pilot 추가 자원·지연 비용 정량화가 부족하다.

## 우리 업무 관점 코멘트

- **RAN1#127 안건 대응: 10.5.3.1 (6GR 하향링크 기반 CSI 획득).** 물리 채널 대신 UE combiner 이후 유효 채널을 보고하자는 Nokia 공저 제안으로, 6GR 다중 안테나 UE의 CSI 보고 대상 논의에 직접 쓸 수 있다.
- 기존 payload 구조를 그대로 쓴다는 점이 표준화 부담을 줄이는 논거가 된다.
- 우리 SLS로 옮기려면 광대역·38.901 채널에서 같은 이득이 나는지 확인해야 한다.
