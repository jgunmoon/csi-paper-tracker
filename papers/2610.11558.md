## Key idea

- 다중 경로 채널은 경로별 rank-one 성분의 합이라는 **저랭크 사전 지식(LRP)** 을 써서, UE에서 학습 가능한 rank-one sensing으로 압축하고 BS에서 rank-one 성분을 합성한다 (Fig. 1).
- LRP에 convolution 잔차 branch를 더한 DCRNetV2로 정확도–복잡도 범위를 넓힌다 (Fig. 2).
- 실외 ray-tracing CSI 벤치마크(Sionna-RT-Mix5)를 새로 공개.

## System model

- FDD wideband OFDM massive MIMO, angular-delay CSI H_a ∈ C^{N_a×N_t} (Sec. II).

## Simulation setup

| 항목 | 값 |
|---|---|
| 채널 모델 / 시나리오 | COST2100, Sionna-RT-Mix5, Shenzhen CBD(OOD), 실측 FDD |
| 지표 | NMSE, FLOPs |
| Payload | CR 1/4–1/32 |
| 코드·데이터 공개 | GitHub 코드 + RT 벤치마크 |

## Results (baseline 대비)

- CR 1/4 indoor: **LRP −13.18 dB @0.68 MFLOPs vs FISTA −10.46 dB @42.99 MFLOPs** (Sec. V). 모델 기반 대비 10 dB 이상 개선 (Abstract).
- DCRNetV2는 최신 Transformer 계열과 비슷한 정확도를 FLOPs ≈ 1/5로 (Abstract, Table II).
- ray-tracing·실측 데이터에서도 일반화 유지 (Sec. VI, 그림 수치 미확인).

## Limitations

- far-field·주파수 불변 배열 응답 가정이라 near-field 광대역에서는 정확도가 떨어질 수 있다(저자 명시).
- 3GPP 코드북·SGCS 비교 없음.

## 우리 업무 관점 코멘트

- **RAN1#127 안건 대응: 9.1.1 (Case 0 CSI 압축).** 물리 구조(저랭크)를 넣은 경량 encoder로 FLOPs를 크게 줄인 사례라, Case 0의 UE 복잡도 대비 성능 논의에 참고할 수 있다.
- 공개 RT 벤치마크와 실측 결과는 Case 0 일반화 평가에 보조 데이터로 쓸 수 있다.
- 우리 평가로 옮기려면 eigenvector 입력·SGCS·eType II 대비로 다시 측정해야 한다.
