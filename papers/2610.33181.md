## Key idea

- 분산 MIMO-OFDM의 coherent joint transmission(CJT)에서 **타이밍 오프셋, CFO, SCO, 위상 잡음, CSI 피드백 지연 동안의 채널 변화**를 함께 넣은 수신 신호 모델을 유도한다 (Sec. II–III).
- 각 손상이 precoder 어긋남, ICI, 유효 채널 이득 감소로 SE를 깎는 경로를 분리하고, SE 손실이 작게 유지되는 요구 조건을 수치로 정한다.

## System model

- 단일 사용자 분산 MIMO-OFDM CJT, 3.5 GHz, 30 kHz SCS, 15.36 MHz 샘플링 (Sec. IV).

## Simulation setup

| 항목 | 값 |
|---|---|
| 채널 모델 / 시나리오 | 광대역 다중 경로(NLOS) 해석 모델 |
| 손상 | 시작 시간 지터, CFO, 클록 오차, 위상 추적 오차, Doppler–지연 곱 |
| 지표 | SE 및 이상적 대비 감소율 |
| 코드·데이터 공개 | 없음 |

## Results (baseline 대비)

- 시작 시간 지터 표준편차 < 샘플 주기 10%(≈ 6.5 ns): SE 손실 0.68%(0 dB) → 0.17%(40 dB) (Abstract).
- 정규화 CFO 표준편차 0.001: 손실 0.05%(0 dB) → 2%(40 dB) (Abstract).
- SNR 26 dB, SE 손실 5% 이하: 클록 오차 ≤ 50 ppb, Doppler–지연 곱 ≤ 0.1, 위상 추적 오차 ≤ 40°; SNR 30 dB에서 Doppler–지연 곱 0.1이면 ≈ 2%, 0.2면 ≈ 9% 손실 (Sec. V).

## Limitations

- 단일 사용자 CJT만 다루고 다중 사용자 간섭은 없다.
- 3GPP 채널 모델이 아닌 해석 모델이라 수치는 조건 의존적이다.

## 우리 업무 관점 코멘트

- **RAN1#127 안건 대응: 직접 해당 없음.** Rel-18/19 CJT CSI(다중 TRP 코드북·TRP 간 오프셋 보고)와 같은 주제지만 현재 추적 중인 안건 항목에는 해당하지 않는다.
- "Doppler–지연 곱 0.1 이하" 같은 CSI aging 요구치는 6GR에서 다중 TRP CSI 보고 주기·예측 필요성을 논의할 때 정량 근거로 쓸 수 있다.
