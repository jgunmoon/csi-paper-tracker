## Key idea

- FDD 예측은 "시간 외삽 + 대역 간 추론"이 겹친 문제인데, 사전학습 CSI 모델의 위치 인코딩은 이를 구분하지 않는다. FAR-CSI는 **시간축과 UL/DL 동작 대역을 함께 나타내는 위치 필드**를 정의한다 (Sec. III–IV).
- 같은 구조화 routing 규칙으로 encoder 위치 할당, decoder 재구성, 미래 DL 목표 선택을 모두 정한다.
- 마스킹 재구성 방식 사전학습 모델을 FDD 예측에 맞춰 쓴다.

## System model

- FDD 다중 반송파 링크, 과거 UL CSI 패치(시간–주파수–안테나) → 미래 DL CSI 4 step (Sec. III).
- 비교용으로 TDD 설정도 평가.

## Simulation setup

| 항목 | 값 |
|---|---|
| 채널 모델 / 시나리오 | LLM4CP 공개 벤치마크, QuaDRiGa 3GPP UMa NLOS |
| UE 속도 | 10–100 km/h |
| 학습 / 시험 데이터 | 같은 분포, 학습 데이터 5–100% 비율 실험 |

| 코드·데이터 공개 | 데이터셋 공개(LLM4CP), 코드 없음 |

## Results (baseline 대비)

- FDD clean 입력: **NMSE 0.150** vs LLM4CP 0.382, Transformer 0.464, WiFo 1.129, UL persistence 1.928 (선형, Table I). LLM4CP 대비 −60.6%, Transformer 대비 −67.6%.
- MRT SE 7.11 vs LLM4CP 6.63, Transformer 6.36 bit/s/Hz (Table I).
- FDD-aware routing vs 일반 routing: NMSE 0.191 → 0.150 (−21.4%, 3 seed) (Table II). 학습 데이터 5%만으로도 전체 데이터 Transformer·LLM4CP보다 낮다 (Fig. 6).

## Limitations

- TDD에서는 입력 SNR에 따라 최선 방식이 바뀌어 일관된 우위가 없다 (Fig. 8).
- 복잡도·추론 지연 분석이 없고, LLM4CP 데이터셋 한 종류만 써서 다른 시나리오 일반화는 미검증.

## 우리 업무 관점 코멘트

- **RAN1#127 안건 대응: 10.5.3.2 (6GR 상향링크 기반 CSI 획득).** FDD에서 UL 측정만으로 DL CSI를 예측하는 방향이라, 6GR에서 SRS 기반 CSI 획득을 FDD까지 넓히는 논의의 성능 근거로 참고할 수 있다.
- 공개 LLM4CP 데이터셋을 써서 우리 예측 모델과 같은 조건으로 비교하기 쉽다. 위치 인코딩 설계만 바꿔 −21% 이득이라는 점은 우리 transformer 예측기에도 바로 시험해 볼 만하다.
- 다만 FDD UL/DL 대역 차이·안테나 보정 오차 등 실제 조건은 없어서, 우리 평가에서는 SGCS와 3GPP FDD 대역 간격으로 다시 확인해야 한다.
