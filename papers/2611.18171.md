## Key idea

- URLLC에서는 평균 채널보다 **드물게 깊게 떨어지는 fading(극값)** 을 미리 맞히는 것이 중요하다. 그런데 MSE loss로 학습한 GRU는 평균 쪽으로 수렴해서 tail을 놓친다 (Sec. I–II).
- 수신 전력의 하위 tail에 **EVT(GPD)** 를 맞추고(GAN-EVT로 파라미터 추정), 그 CDF로 quantile 수준 α를 샘플마다 정하는 **adaptive quantile loss**를 GRU 학습에 쓴다. 임계값 이상 샘플은 기존 MSE loss를 쓴다 (Sec. III, eq. 6).
- 모델 구조는 그대로 두고 loss만 바꾸므로 추론 복잡도는 같다.

## System model

- SISO, 고정 송신 전력. 예측 대상은 **수신 전력(|h|²)** 이고 복소 채널·위상은 다루지 않는다 (Sec. II-A).
- Rx가 tail 분포를 추정해 Tx에 알리고, Tx 측 GRU가 다음 1–5 sample(최대 10 ms)의 수신 전력을 예측한다는 개념 구조. 피드백 양자화·지연은 모델링하지 않았다.
- GRU 1층 50 unit, 7,950 파라미터 (Sec. IV-B).

## Results (baseline 대비)

- baseline은 **같은 GRU + MSE loss** 하나뿐이다 (자기 ablation).
- **Tail 예측**: −49 dBm 아래 값 중 맞힌 비율 21% vs MSE-GRU 7% (LB = 5, Sec. IV-C). 예측된 tail 비율 7.26% vs 실측 7.49% vs MSE-GRU 2.4%.
- **Tail MAE (Fig. 4, 그래프 읽음)**: horizon 1–5 전체에서 MSE-GRU보다 ≈ 3 dB 낮다. LB 15가 LB 5보다 약간 낫다.
- **평균 구간**: −49 dBm 위 값에서는 MSE-GRU가 MAE 0.5 dB 미만 차이로 더 낫다 (Sec. IV-C).
- 복잡도: 두 모델 모두 7,950 파라미터, 예측 1회 약 30 µs (Sec. IV-C).

## Limitations

- **수신 전력(스칼라)만 예측**한다. MIMO precoding이나 CSI 피드백에 필요한 공간·위상 정보가 없다. CQI/link adaptation 관점의 기법이다.
- 차량 엔진룸 60 GHz 단일 링크 측정 하나이고, 학습·검증이 같은 측정 데이터다. 셀룰러(UMa/UMi, 이동 UE) 채널에서 검증하지 않았다.
- 모델 기반 예측기(AR/Kalman)나 quantile regression 고정 q 같은 다른 baseline과 비교하지 않았다.
- GPD 파라미터를 고정(정상성 가정)으로 썼다. 비정상 채널에서 실시간 갱신은 future work (Sec. V).
- 2025년 IEEE CL 게재 논문을 2026-11에 arXiv에 올린 것이다.

## 우리 업무 관점 코멘트
- 셀룰러 CSI 압축·예측과 직접 맞지 않는 링크(차량 내부 60 GHz SISO)다. 다만 **"tail 이벤트를 놓치지 않도록 loss를 바꾼다"** 는 아이디어는 NR/6G URLLC의 CQI 예측이나 link adaptation용 예측기 학습에 옮겨 쓸 수 있어 후보에 남겼다.
- TR 38.843 prediction 평가(SGCS/NMSE, 복소 채널, UE 속도별)와 거리가 멀어 성능 비교 근거로는 쓰기 어렵다. 우리 예측기의 deep-fade 구간 오류를 따로 보는 지표(tail MAE, 예측 tail 비율)를 정할 때 참고할 만하다.
- 재현 난이도: 모델은 단순하지만 측정 데이터와 GAN-EVT 코드가 공개되지 않아 그대로 재현하기는 어렵다.
