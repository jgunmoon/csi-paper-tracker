## Key idea

- SSB 빔 측정 단계에서 RSRP 대신 RSRQ, SINR을 빔 선택 지표로 쓰면 나은지, 세 가지 UE–gNB 연결 전략과 함께 비교한다 (Sec. III).
- 간섭 추정이 빔 index와 무관하면 RSRP·스칼라 RSRQ·SINR이 **같은 빔을 고른다**는 등가 조건을 보인다.
- 남는 성능 격차가 지표가 아니라 **코드북 양자화** 때문임을 RZF 완전 CSI 상한으로 확인.

## System model

- 7셀(21 섹터) UMi, gNB 4×4 dual-pol(32 port, 38.901 패턴), UE 단일 안테나 (Sec. IV).

## Simulation setup

| 항목 | 값 |
|---|---|
| 채널 모델 / 시나리오 | Sionna 38.901 UMi 다중 셀, 1000 drop |
| 안테나 | gNB 32 port, UE 1 |
| 지표 | SE, 지표 분포, PCA |
| 코드·데이터 공개 | 없음 |

## Results (baseline 대비)

- 평균 SE: **순차 연결 1.23 bps/Hz vs Hungarian(전력 최적) 1.10**, RZF 상한 1.49 (Table II).
- 방향성 RSRQ는 대칭 간섭에서 기하적으로 나쁜 빔을 골라 가장 나쁜 전략 (Sec. V).
- PCA: 두 성분이 분산의 97.6% 설명, PC1(75.5%)은 일반 링크 품질 축 (Table I).

## Limitations

- SSB 단계만 다루고 CSI-RS 빔 정밀화·UE 이동은 없다.
- 단일 안테나 UE라 UE 빔 쌍 선택은 빠져 있다.
