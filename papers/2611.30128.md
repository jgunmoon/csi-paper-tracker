## Key idea

- MIMO-OFDM 채널 이력을 (frequency × time × antenna-pair) 3D 텐서로 보고, 3D patch tokenization과 축별로 나눈 attention(F→T→A)을 쓰는 ViT 예측기를 만든다 (Sec. III).
- ViT 성능은 patch 크기에 민감하고, 적절한 patch 크기는 coherence time/bandwidth에 따라 달라진다. 그래서 **2차 통계(Jakes 시간 상관, PDP 주파수 상관)로 LMMSE 예측 오차를 계산해 시간·주파수 patch 길이를 고른다** (Sec. IV-A, Algorithm 1).
- patch 크기가 바뀌어도 다시 학습하지 않도록, 기준 patch embedding을 **채널 통계 기반으로 resize** 한다(FlexiViT의 pseudo-inverse resize를 통계 버전으로 바꾼 것). 학습 때는 여러 patch 크기를 샘플링해서 하나의 backbone을 공유한다 (Sec. IV-B, V).

## System model

- TDD MIMO-OFDM. UE(N_t = 2)가 UL pilot을 보내고 BS(N_r ∈ {2, 8}, UPA λ/2)가 UL 추정 채널로 DL 채널을 예측한다 (reciprocity 가정) (Sec. II, VI-A).
- 입력은 **LS 추정 + 선형 보간 CFR** (DM-RS 2 symbol/slot) — perfect CSI 아님 (Sec. II-C, VI-A).
- 출력은 다음 L개 OFDM symbol의 복소 CFR 전체(모든 subcarrier·안테나 쌍). 학습 loss는 horizon 전체 NMSE (eq. 14).
- 피드백 없음(TDD, BS 측 예측) → 양자화·피드백 지연 이슈 해당 없음.

## Results (baseline 대비)

- **Resizing ablation (Table I, NMSE dB)**: Eb/N0 10 dB에서 statistical resize −12.218 vs Lin.-pinv(FlexiViT 방식) −11.675 vs Linear −11.938 vs Nearest −11.487 vs Fixed(resize 없음) −8.827.
  pseudo-inverse resize 대비 이득은 약 0.3–0.5 dB로 작고, resize를 아예 안 한 경우 대비로는 약 3.4 dB.
- **Attention 구성 (Table II)**: Eb/N0 10 dB에서 FTA −12.596 dB vs FT −12.441 dB vs T-only −12.076 dB. 공간 attention 추가 이득은 약 0.15 dB.
- **Baseline 비교 (Fig. 3–5)**: seen(CDL-A)·unseen(CDL-D) 조건 모두에서 No prediction, LMMSE, Kalman, LSTM, Transformer, LLM4CP, ChannelMamba보다 NMSE가 낮고 achievable rate가 높다고 서술 (Sec. VI-C).
  그림 수치는 텍스트에서 확인하지 못해 적지 않는다 (`?`). 이 실험은 모두 Eb/N0 = −4 dB 한 점이다.
- **적응 (Fig. 6–7)**: 시나리오가 바뀌는 시퀀스에서 fixed-patch ViT보다 NMSE가 안정적이고, 테스트 patch 크기가 바뀌어도 FER이 유지된다고 서술. 재구성 지연 9.148–32.371 ms, 200 frame마다 1회라 frame당 0.0457–0.1619 ms (fixed-patch 추론 지연의 1.60–3.28%) (Sec. VI-D).
- **복잡도 (Table III)**: L = 56일 때 UV3CP 119.944 M 파라미터·457.865 MiB vs fixed ViT 12개 1439.324 M·5494.379 MiB, 추론 2.158 GFLOPs (fixed ViT와 동일).
  L = 14/98에서는 31.175 M/208.712 M 파라미터, 0.782/3.535 GFLOPs. 출력 head가 horizon에 비례해 커진다.

## Limitations

- 이득의 핵심이 "patch 크기 하나로 여러 시나리오 대응 + 모델 저장량 절감"이다. 단일 최적 patch ViT 대비 정확도 이득은 Table I 기준 sub-dB 수준이다.
- 패치 선택·resizing에 쓰는 2차 통계를 **CDL 파라미터에서 바로 계산한(model-consistent) 값**으로 썼다 (Sec. VI-B 끝). 실제로는 Doppler·PDP를 추정해야 하고, 추정 오차의 영향은 평가하지 않았다.
- 대역폭이 128 subcarrier(약 1.9 MHz)로 작고 안테나도 최대 8×2라, 32T 이상 NR 설정에서 3D 토큰 수와 출력 head(파라미터가 K·L·N_r·N_t에 비례) 크기가 어떻게 될지 검증되지 않았다.
- 파라미터 수가 31–209 M으로 크다. 출력 head가 대부분을 차지하는 것으로 보여 실장 부담이 있다.
- baseline 비교 그림이 Eb/N0 = −4 dB 한 점이고, 텍스트에 수치가 없다. 코드도 공개하지 않았다.

## 우리 업무 관점 코멘트

- Rel-19 AI/ML CSI prediction(UE 측 one-sided)이 아니라 **TDD gNB 측 SRS 기반 예측**이다. 다만 CDL + LS 추정 입력 + 모델 기반(LMMSE/Kalman)·최신 DL(LLM4CP, ChannelMamba) baseline + unseen CDL 일반화까지 갖춰서 평가 구성은 탄탄한 편이다.
- "채널 통계로 모델 구성을 고른다"는 아이디어는 시나리오·속도 일반화(TR 38.843의 generalization case)를 모델 하나로 처리하는 방법으로 참고할 만하다.
  그러나 SGCS·eType II 기반 비교가 없고 대역폭이 작아서 우리 평가 체계 수치와 바로 비교하기는 어렵다.
- 재현 난이도는 중간: Sionna CDL과 Sec. VI의 설정만으로 다시 만들 수 있지만 코드가 없다.
